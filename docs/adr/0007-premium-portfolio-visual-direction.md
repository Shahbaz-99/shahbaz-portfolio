# ADR 0007: Premium portfolio visual direction

**Status:** Accepted.
**Context:** The portfolio needs a cohesive, readable design that feels personal and professional across the homepage and supporting routes.
**Decision:** Use a warm cream, burgundy, dusty rose, and navy palette with Instrument Sans as the single type family. Apply restrained glass surfaces, subtle ambient gradients, clear section hierarchy, compact responsive spacing, and CSS-first motion that respects `prefers-reduced-motion`. Project previews must be based on the projects' actual workflows and features. Keep email and social links, but do not provide a contact form or contact section.
**Consequences:** Shared components retain Astro's static rendering and existing routes. Light and dark themes use the same visual direction, and project summaries expose distinct case-study and repository links.
